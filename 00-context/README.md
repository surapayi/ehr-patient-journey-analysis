# Context: The Broad Patient Journey

This folder holds my first, wider view of the patient journey in an EHR. It is background for the main project in this repo, the outpatient orthopedic knee pain consult.

## What this covers

The full path of a patient through a clinic or hospital:

patient access → registration → scheduling → check-in → encounter → orders → results → checkout → billing

## What's in this folder

- **Swimlane diagram:** maps the full patient journey to the EHR workflow, by role. [View the diagram](swimlane-patient-journey.png)
- **Data and KPI map:** shows which data is created at each step and which KPIs it could support. (data-and-kpi-map.md)
- **Scope and rationale:** explains why I chose this approach. (scope.md)

## Why it's here

I started with the whole journey to learn how the pieces fit together. It was too broad to go deep on, so I narrowed the project to one clinical scenario. The knee consult in the main project is a zoomed-in version of this larger map.

## A note on sources

I have not worked in a clinic. This is a reference workflow built from public sources, course material, and healthcare IT standards. Real clinics will differ.
